# PartsNAS documentation

The [README](../README.md) is the short version: what PartsNAS is, how to install it, and the disclaimer.
These pages go into how to use it.

| Page | What it covers |
|---|---|
| [BOM and building a board](bom.md) | Import a KiCad BOM, match it to your stock, skip / edit / place lines, the board view, printing a pick list with prices |
| [KiCad](kicad.md) | Pick real parts while you draw (the HTTP library), naming symbols and footprints, several footprints per part, exporting a BOM with MPN |
| [Troubleshooting](troubleshooting.md) | The error messages you can meet, what they mean and what to do |

More pages (getting started, parts and stock, suppliers and API keys, quotes and invoices, backups and updating)
are planned; until they exist, their content is in the README.

Everything here describes what PartsNAS does *now*. Where something has only been checked against a
specification and not yet in real use, the page says so.
